What this is

Every value the three sites publish over OPC UA, mapped onto the HCW standard model (hcw/<site>/air-separation/<unit>/<equipment>/<point>). Per site: the native browse path, its NodeId, the unit it publishes, and the conversion to the standard (x = the native value). This mapping is open reference material, generated from the code and tested against the live servers: use it to build the DataOps layer. Live values come from each site's DCS (/api/mapping) and are converted with the formula shown, so you can see each conversion work.
